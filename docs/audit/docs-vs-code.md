Documentation vs code audit
Audited: 2026-09-26.
Repository: https://github.com/stpatrickghost/be-energy.
Baseline: 8b1a4944de1058b3afc4298dbe11d3d5b5f8f671 (before this documentation-only change).
Decision boundary: the product lane is undecided. The token is not an I-REC. Do not add certificate, ESG-compliance, carbon-offset, or renewable-use entitlement claims.
What the developer has built
The implementation is an experimental cooperative-management application: a Next.js dashboard, Supabase-backed operational records and authentication, and Stellar/Soroban token operations. It has cooperative/member/meter/reading workflows, routes and database entities named certificates and retirements, custodial server-side mint/burn flows, wallet utilities, and partial DeFindex integration. These implementation names do not establish certification, environmental attributes, or a committed product lane.

The Rust workspace contains a fungible token, proportional distribution, proposal-only governance, and a factory. The factory expects an external registry; a production registry implementation is not present. A token transfer primitive is not a P2P marketplace or payment settlement system.

Scope and method
Compared the README, all numbered docs/1-PLAN.md through docs/9-ARCHITECTURE-MARCH.md, docs/next-steps/ (including the extensionless QA report), simulator grant draft, brand materials, net-vs-gross research, tooling issue notes, package manifests, environment example, scripts, API handlers, validation schemas, auth utilities, contract sources, and tests. There is no separate checked-in OpenAPI specification; API notes are embedded in the numbered docs and testing guide.

Evidence below is relative to this checkout. Claim locations refer to the baseline, including README text withdrawn by this patch. Recorded means a mismatch is documented here, not repaired in application code. Withdrawn/fenced means a misleading README promise or setup instruction has been removed or explicitly qualified. Link repaired means a missing target no longer appears as a working reference.

This is not a security review, legal opinion, hardware verification, deployment attestation, or external-registry audit. Hosted demo accounts, external awards/customer interviews, and live contract addresses were not independently verified. Historical research and proposed SQL are not evidence of deployed capabilities.
